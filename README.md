# PK Direction Consultation module (public shell)

This repository holds only the public shell of the pre-work module for the DOH BLHSD consultation on the future direction of PuroKalusugan. It contains no consultation content and no participant data. The module text and all answers are stored separately and are available only with an access code.

The in-room module (`room.html`, `room.js`, `pptx.js`, `room.css`) runs the two-day consultation: slides, votes, notes and results for participants, group devices, staff and the projector. It also holds no consultation content. The slides are uploaded by staff and stored in the database. `dev-room.js` is a local test backend used only on localhost with `?mock=1`.
